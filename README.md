### Инструкция по установке
Инструкцию по установке нужно выполнить только при первом запуске.
Установите приложение Ollama \
Для этого перейдите на сайт по ссылке https://ollama.com/ и нажмите Download в правом верхнем углу\
После этого запустите скачавшийся OllamaSetup и нажмите Install.

После завершения работы установщика откройте командную строку (пуск => поиск=> "cmd" или "командная строка") и введите команду: \
ollama run qwen2.5:3b \
После этого будет загружена БЯМ на 2 Гб 

Всю эту настройку потребуется провести единожды

### Запуск
Для запуска на виндовс нажмите запуск.bat \
Программа сначала установит все необходимые библиотеки. \
После первой успешной установки, НАЖМИТЕ ENTER!!!

Затем файл запустит веб-версию сервиса \
Для работы не закрывайте файл .bat (консоль)


### Работа программы
При запуске веб-версии Вам будет предложено ввести ссылку на товар, \
а также критерии, согласно которым нужно оформить Решение.

Вы можете загрузить сразу несколько ссылок, для этого нажмите "Добавить URL" \
Программа будет составлять решения по ссылкам по очереди

После нажатия кнопки "Создать отчёт" программа откроет ссылку в браузере \
Вы можете работать, пока программа работает в фоне\
Однако не заходите и не закрывайте вкладки ссылок, над которыми она работает, до конца её работы.

После этого в папке с программой, там же где запуск.bat, \
Создастся файл Результат_[номер критерия]_[название товара].docx
