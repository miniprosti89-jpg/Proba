### Инструкция по установке

### Запуск
Для запуска на виндовс нажмите запуск.bat \
Программа сначала установит все необходимые библиотеки, это может занять пару минут. \


Затем файл запустит веб-версию сервиса \
Для работы не закрывайте файл .bat (консоль)


### Работа программы
При запуске веб-версии Вам будет предложено ввести ссылку на товар, \
а также критерии, согласно которым нужно оформить Решение.

Вы можете загрузить сразу несколько ссылок, для этого нажмите "Добавить URL" \
Программа будет составлять решения по ссылкам по очереди

После нажатия кнопки "Создать отчёт" программа откроет ссылку в браузере \
Подождите пару секунд, пока в правом верхнем углу не появится плашка с выбором названия \
Следуйте инструкциям: Вам будет необходимо выбрать область, где написано название товара.

Нажмите "Включить выбор", наведите курсор на название (подсветится оранжевым), кликните (обведётся красным) и нажмите "Подтвердить". Названия нет — жмите "Подтвердить" без выбора.

Дальше появится плашка для описания — выбирайте так же. ⚠️ Перед "Подтвердить" проверьте, что красная рамка обводит именно текст описания, а не что-то другое — иначе часть текста может не попасть в документ. Если описание в нескольких блоках — после "Подтвердить" выберите следующий блок так же; когда блоков (или описания) больше нет — нажмите зелёную "Завершить".

Пока программа фотографирует, страница сама дёргается и прокручивается — это нормально, просто подождите и не трогайте мышь и клавиатуру.

После этого в папке с программой, там же где запуск.bat, \
Создастся файл Результат_[номер критерия]_[название товара].docx - это и есть Решение
